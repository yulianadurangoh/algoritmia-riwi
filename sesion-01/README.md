# Rueda Libre — Asistente de taquilla

Algoritmos en pseudocódigo (PSeInt) para la taquilla de **Rueda Libre**, emprendimiento de Medellín que alquila bicicletas y organiza recorridos guiados. Proyecto de Algoritmia 1 — Nodo Digital.

**Versión actual: v0.1** (cuatro algoritmos secuenciales de la Semana 1)

## Algoritmos

| Archivo | Qué hace |
|---|---|
| `algoritmos/01_cotizacion_basica.psc` | Cotiza el alquiler de una bicicleta urbana por horas ($10.000 la hora, casco y candado incluidos). |
| `algoritmos/02_cotizacion_recorrido.psc` | Cotiza un recorrido guiado para un grupo: valor total, anticipo del 30 % y saldo pendiente. |
| `algoritmos/03_cuenta_grupo.psc` | Calcula la cuenta de un grupo (alquiler + recorrido + aporte voluntario del 10 %) y la divide entre las personas, redondeando hacia arriba a la centena. |
| `algoritmos/04_suma_dos_numeros.psc` | Suma dos números que escribe la persona. Es el ejemplo "Resolver una suma" de la Semana 1. |
